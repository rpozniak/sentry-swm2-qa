# Докази

Очищені логи зберігаємо тут або у підкаталогах за версіями.
Рекомендована назва: `2.1.0_TC-LM-01_run-001.log`.
У логах мають бути команда, відповідь, версія та контекст перевірки.

Сирі логи тримаємо лише у `logs/raw/`: цей каталог ігнорується Git.
Перед копіюванням доказів прибираємо паролі Wi-Fi, акаунта та інші секрети.
