# Ручні перевірки SENTRY SWM-2

Фізичні кейси TC-LM-09, TC-LM-10, TC-RL-02 і TC-RL-03 не виконано на обох версіях. Поточний результат кожного параметра — **Not Run**. Цей журнал доповнює [кейси](TEST_CASES.md), [матрицю](TRACEABILITY.md) та [автоматизовані виконання](EXECUTION_RESULTS.md).

## Черга на один ручний прогін

Почати з установленої 2.3.0: кольори RGB, яскравість у чотирьох режимах, зовнішній LED. Це не вимагає підключення реле. Після цього — ті самі перевірки на 2.1.0, якщо залишається час на зміну версії й відновлення сесії. Контакти реле перевіряти лише з підключеним сумісним модулем. Те, що не почали перевіряти, залишається Not Run.

Орієнтир на годину: 5 хв підготовка; 15 хв RGB; 5 хв зовнішній LED; 10 хв контакти за готового модуля; решта — друга версія та внесення доказів. Це розподіл часу, а не результат перевірок.

## Підготовка

1. Закрити автотести. Відкрити UART-термінал на 115200 8N1 без local echo. Із кореня репозиторію:

   ```bash
   source .venv/bin/activate
   python -m serial.tools.list_ports -v
   python -m serial.tools.miniterm <port> 115200 --eol LF
   ```

2. Виконати `version`, `whoami`. Якщо потрібне відновлення — `reconnect`, потім `login <user> <P0>`. Для beta перевірити `guard status`; Guard має бути disarmed. Пароль у доказах приховати.
3. Підготувати початковий стан командами нижче, кожну вводити окремо:

   ```text
   state 1
   distance stop
   relay auto off
   relay schedule off
   relay off
   lamp timer 0
   lamp mode solid
   lamp color white
   lamp brightness 50
   lamp off
   ```

4. Записати версію й загальний вигляд підключення. Файл фото має показувати реальний стенд; схему HIL не використовувати замість фото. Для кожного виконаного параметра записати фактичний результат і посилання на фото або відео.

## TC-LM-09

Вимога LM-2. Використовується вбудований RGB LED GPIO48. Виконати `lamp on`, `lamp mode solid`, `lamp brightness 50`. По черзі задавати `lamp color <name>` для white, red, green, blue, yellow, purple, cyan, orange. Після кожної команди спостерігати саме фізичний колір і зберегти доказ.

Pass для параметра: LED світить кольором із назви. Значення RGB у UART самостійно не підтверджує фізичний колір. Після кейсу — `lamp color white`, `lamp off`.

## TC-LM-10

Вимоги LM-3, LM-4. Виконати `lamp on`, `lamp color white`. Для кожного режиму solid, blink, breathe, rainbow:

1. `lamp mode <mode>`.
2. `lamp brightness 100`; спостерігати кілька циклів.
3. `lamp brightness 50`; спостерігати ті самі умови.
4. `lamp brightness 0`; перевірити відсутність світіння лампи.

Зняти одне безперервне відео 100 → 50 → 0 для режиму, бажано з фіксованою експозицією. У breathe порівнювати максимум циклу, у blink — увімкнену фазу. Pass: зміна яскравості видима, при 0% світіння відсутнє. Виміряну світлову потужність не заявляти. Після кейсу — solid, white, brightness 50, lamp off.

## TC-RL-02

Вимога RL-1. Зовнішній LED: **3V3 → резистор 220–330 Ом → анод LED; катод → GPIO4**, active LOW. Підключення змінювати при вимкненому живленні. Модуль реле для цього кейсу не потрібен.

1. `relay off`: зовнішній LED не світить.
2. Пауза понад 1 с; `relay on`: зовнішній LED світить.
3. Пауза понад 1 с; `relay off`: LED знову не світить.

Для ON і off записати окремі результати та фото/відео. Спостерігати зовнішній LED GPIO4, а не вбудований RGB.

## TC-RL-03

Вимога RL-1. Передумова — готовий модуль реле зі звіреним рівнем IN та типом тригера. Наявний модуль має живлення котушки 5 В; його сумісність із GPIO8 має бути перевірена перед підключенням. Силові контакти вільні від навантаження й зовнішнього джерела. Мультиметр — у режимі прозвонювання контактів.

| Команда | COM–NO | COM–NC |
|---|---|---|
| relay off | Розімкнено | Замкнено |
| relay on | Замкнено | Розімкнено |

Між командами — пауза понад 1 с. Зафіксувати фактичні покази мультиметра для кожної пари та стану; клацання або LED модуля не замінюють вимірювання. Наприкінці — relay off.

Якщо перевірку почали, але сумісність або підключення не підтверджені, результат Blocked із конкретною причиною. Без спроби виконання залишається Not Run.

## Після виконання

Повернути lamp mode solid, lamp color white, lamp brightness 50, lamp timer 0, lamp off, relay off, relay auto off, relay schedule off, distance stop, health interval 30, health on. Вихід із miniterm — Ctrl+].

Очищені UART-логи й фізичні докази додавати в окремий каталог `logs/manual-<version>-<run>/`. Для кожного параметра нижче замінити Not Run фактичним статусом, коротко описати спостереження та додати відносне посилання на доказ. Після цього узгодити підсумок кейсу в TRACEABILITY.md, EXECUTION_RESULTS.md, REPORT.md та презентації. Невиконані параметри залишаються Not Run; причина — «не виконано в межах ручного прогону».
