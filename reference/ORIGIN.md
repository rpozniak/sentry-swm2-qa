# Походження матеріалів

Матеріали скопійовано з наданого користувачем `fw_7.zip`.
PRD.md, WIRING.md, HW-17.md, README.md і tools/ збережено без змін.
Стартовий образ перенесено до локальної папки firmware/.
COURSEWORK.pdf є копією наданої умови курсового проєкту.

У наданому знімку повідомлення куратора є уточнення обсягу:
для виступу 1-3 фічі, для технічної здачі без виступу 5 фіч.
Спосіб здачі й конкретні фічі ще не обрано.

Ці матеріали є джерелом вимог. Початкові файли поза цією папкою не змінено.
