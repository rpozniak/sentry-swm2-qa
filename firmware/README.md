# Стартова прошивка

Для первинного прошивання потрібен `sentry_fw7_v2.1.0_merged.bin` із наданого на курсі архіву `fw_7.zip`. Скопіювати його в цю папку. Сам образ і архів виключені з Git; контрольна сума збережена в [SHA256.txt](SHA256.txt).

Перевірка образу на macOS:

```bash
cd firmware
shasum -a 256 -c SHA256.txt
```

Порядок прошивання та початкового connect/register/login наведений в [оригінальній інструкції](../reference/README.md). У її команді прошивання використати шлях `firmware/sentry_fw7_v2.1.0_merged.bin`, якщо термінал відкритий у корені цього репозиторію. `esptool` установлюється окремо лише для первинного прошивання; автотести використовують залежності з `requirements.txt`.

Версія 2.3.0 встановлюється на пристрій через OTA. Виконаний перехід 2.1.0 → 2.3.0 підтверджує [лог](../logs/ota-01/2.1.0-to-2.3.0.log). Автотести не встановлюють і не змінюють прошивку. Для тестування вже прошитої плати локальний образ не потрібен.
